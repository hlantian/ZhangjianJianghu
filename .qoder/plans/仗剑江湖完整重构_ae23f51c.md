## 总体架构

```

├── frontend/                    # Vue3 前端
│   ├── src/
│   │   ├── api/                 # REST API 调用
│   │   ├── components/          # 游戏组件
│   │   ├── views/               # 页面视图
│   │   ├── stores/              # Pinia 状态管理
│   │   ├── websocket/           # WebSocket 通信
│   │   └── utils/               # 工具函数
│   ├── package.json
│   └── vite.config.ts
├── backend/                     # Java Spring Boot 后端
│   ├── src/main/java/com/zjjh/mud/
│   │   ├── config/              # 配置类
│   │   ├── controller/          # REST + WebSocket 控制器
│   │   ├── service/             # 业务逻辑层
│   │   ├── mapper/              # MyBatis-Plus Mapper
│   │   ├── entity/              # 数据库实体
│   │   ├── dto/                 # 数据传输对象
│   │   ├── websocket/           # WebSocket 处理

│   │   │   ├── combat/          # 战斗系统
│   │   │   ├── room/            # 房间系统
│   │   │   └── timer/           # 定时器系统
│   │   └── common/              # 通用工具
│   ├── src/main/resources/
```

## 数据库设计 (database/schema.sql)

### 核心表结构

**1. users (用户账户表)** - 对应原 MySQL mytest 表
- id, username, password(BCrypt), sex(m/f), create_time, last_login_time, status

**2. players (玩家角色表)** - 对应 YPlayer + YActor 全部属性
- id, user_id, name, nick, title, describe, sex, age, icon_no
- room_id (当前房间), x, y (房内坐标)
- body(气血), max_body, energy(精力), max_energy, add_max_energy
- internal_force(内力), max_internal_force, add_max_internal_force
- experience(经验), potential(潜能), goodness_count(正气值)
- food(食物), max_food, drink(饮水), max_drink
- weight(负重), max_weight, deposit(存款)
- begin_arm(先天臂力), begin_learn(先天悟性), begin_force(先天根骨), begin_dodge(先天身法)
- last_arm(后天臂力), last_learn(后天悟性), last_force(后天根骨), last_dodge(后天身法)
- inhere_attack(固定攻击力), powerup_attack, append_attack, force_attack, weapon_attack
- inhere_defense(固定防御力), powerup_defense, append_defense
- feature(容貌), add_feature, luck(福缘), add_luck
- wimpy(逃跑系数), free_time, busy, faint_time, sleep_time
- kill_times, be_kill_times, pk_times, be_pk_times, city_kill, give_thing
- faction_id, faction_title, is_faction_owner, party_value(门派评价), court_value(朝廷声望), society_value(江湖声望)
- online_time, last_online_time, player_level, player_sleep_skip, player_renew, now_work
- close_chat, close_rumor, close_newbie, close_party, close_faction_party
- player_x, player_y (房内位置), status, adversary(对手), follow_you, you_follow
- teacher_name, school, school_place(辈分), all_enemy_list, all_skills_list, work_skills
- weapon_name, weapon_type, weapon_attack, cloth_name, armor, hat, shoe, flower, ring, necklace, bangle
- ck_level(仓库等级), all_ck_list(仓库物品), quest_list(任务列表)
- death_mode, not_dead, come_in(新人登录步骤), noaccept, wiz_close_chat, play_close_chat, play_say_speed

**3. rooms (房间表)** - 对应 YRoom + YAbstractRoom
- id, room_path(如 /room/华山/华山脚下), name, description, type(普通/银行/当铺/...)
- forbid_fight, boss_name, food_consume, update_time_interval, destroy_list, play_list_quit

**4. room_exits (房间出口表)** - 房间连接关系
- id, room_id, direction(东/南/西/北/上/下/出口名), target_room_id, is_hidden(暗门)

**5. npcs (NPC表)** - 对应 YNPC + YActor
- id, name, room_id, place, school, allow_prentice, provide_quest
- need_pate, need_kill_by_self, need_ge_by_self, unite_kill
- 各种对话字段(answer_for_agree_prentice, npc_say_when_no_quest, npc_say_when_giveup, npc_say_when_be_give, npc_say_when_end_quest, player_say_when_giveup)
- appraise_name, body, max_body, energy, max_energy, internal_force, max_internal_force
- inhere_attack, inhere_defense, experience, level, icon_no, sex, age, all_skills_list
- killer_name, be_kill_times, all_enemy_list, death_mode, not_dead

**6. things (物品定义表)** - 对应 YThing + YAbstractThing
- id, name, font_name(显示名), weight, price, describe, quantifier(量词), thing_type(0/1/2), varient_name
- category(武器/防具/食物/药品/书籍/材料/其他), sub_type(剑/刀/拳/甲/帽/鞋/戒指/项链/手镯/花)

**7. player_things (玩家物品表)** - 玩家拥有的物品
- id, player_id, thing_id, count, equipped(是否装备), slot(装备位置)

**8. room_things (房间物品表)** - 房间内的物品
- id, room_id, thing_id, count

**9. wugong (武功表)** - 对应 YWugong
- id, name, description, menpai(门派), leixing(类型:拳法/掌法/剑法/暗器等)
- zhaoshu(招数列表,空格分隔), fangshouli(防守力)
- neigong_needed, jiben_needed, jingyan_needed, jingli_used, qianneng_used
- is_special(是否特殊武功), corresponding_basic(对应基本武功), all_unique_skill(绝招列表)

**10. wugong_moves (武功招数表)** - 拆分招数
- id, wugong_id, move_name, gongjili(攻击力), miaoshu(描述模板), usable_level(使用等级)

**11. player_skills (玩家技能表)** - 玩家已学武功
- id, player_id, wugong_id, level(等级), is_enabled(是否启用), is_basic(是否基本武功)

**12. base_skills (基本武功表)** - 基本武功等级
- id, player_id, skill_type(拳法/指法/掌法/腿法/手法/爪法/轻功/内功/招架/读书), level

**13. factions (门派表)** - 对应 YFaction
- id, name, banner(口号), owner_id(帮主), color, power(势力值), player_amount, close(团结度), is_school(是否门派)

**14. quests (任务表)** - 对应 YQuest
- id, quest_type(kill/send/city_kill), target, target_type, thing(送物品), time_limit
- reward_exp, reward_potential, reward_appraise, reward_money, npc_id(发放NPC)

**15. player_quests (玩家任务表)** - 玩家当前任务
- id, player_id, quest_id, times(连续次数), status(进行中/已完成/已放弃)

**16. chat_messages (聊天记录表)** - Redis缓存+MySQL持久化
- id, channel(say/chat/rumor/newbie/party/faction/wiz/system), player_id, player_name, message, create_time

**17. system_settings (系统设置表)** - 对应 webmud.conf
- id, key, value, type(string/long/float), description

**18. warehouse (仓库表)** - 对应 ycangkuroom
- id, player_id, thing_id, count

## 后端实现 (backend/)

### Phase 1: 项目骨架与基础设施

**1.1 Maven项目初始化 (pom.xml)**
- Spring Boot 3.2.x parent
- 依赖: spring-boot-starter-web, spring-boot-starter-websocket, spring-boot-starter-data-redis, mybatis-plus-spring-boot3-starter, mysql-connector-j, jjwt, lombok, hutool

**1.2 配置文件 (application.yml)**
- MySQL连接池, Redis连接, WebSocket配置, JWT密钥, 游戏数据路径

**1.3 通用基础类**
- `Result<T>` 统一响应体
- `GlobalExceptionHandler` 全局异常处理
- `JwtUtil` JWT生成/验证
- `JwtAuthFilter` JWT认证过滤器
- `RedisConfig` Redis序列化配置
- `WebSocketConfig` WebSocket+STOMP配置
- `MyBatisPlusConfig` 分页插件+自动填充

### Phase 2: 用户认证模块

**2.1 实体与Mapper**
- `User` 实体, `UserMapper`

**2.2 Service层**
- `AuthService` - 注册(login2逻辑)、登录(login1逻辑)、密码修改(upass逻辑)
- 登录成功后生成JWT，将玩家数据加载到Redis缓存

**2.3 Controller**
- `AuthController` - POST /api/auth/register, POST /api/auth/login, POST /api/auth/password
- `PlayerController` - GET /api/player/profile, POST /api/player/create (新玩家创建)

### Phase 3: 游戏引擎核心 (game/ 包)

**3.1 游戏对象模型** - 对应原C++类层次
- `GameObject` (基类，对应YMUDObject) - 属性系统、定时器
- `GameActor` (对应YActor) - 气血/精力/内力/攻击/防御/装备/年龄/死亡等
- `GamePlayer` (对应YPlayer) - 继承GameActor，玩家专属属性(食物/存款/帮派/技能等)
- `GameNPC` (对应YNPC) - 继承GameActor，NPC专属(收徒/任务/对话)
- `GameRoom` (对应YRoom) - 房间(出口/NPC列表/物品列表/禁止战斗等)
- `GameThing` (对应YThing) - 物品(名称/重量/价格/类型/数量)
- `GameWugong` (对应YWugong) - 武功(招数/攻击力/门派/类型)
- `GameFaction` (对应YFaction) - 门派/帮派
- `GameQuest` (对应YQuest) - 任务系统

**3.2 游戏引擎**
- `GameEngine` (对应YWebMUD) - 引擎启动/停止、全局状态管理
- `RoomManager` (对应YMap) - 房间加载/缓存(Redis)/卸载
- `PlayerManager` (对应YPlayerManager) - 在线玩家管理
- `SessionManager` (对应YSessionManager) - 会话管理
- `ChatManager` (对应YChatManager) - 聊天频道管理
- `CommandManager` (对应YCommand) - 命令路由
- `TimerManager` (对应YTimer) - 定时任务(气血恢复/年龄增长/物品刷新/掉线检测)

**3.3 命令系统** - 对应 ycommand.cpp + yplayer.cpp 全部命令
- `CommandRouter` - 命令解析与分发(对应YCommand::executeCommand)
- `CommandTranslator` - 命令别名(对应YCommand::translate)
- 命令处理器(按原项目分类):
  - `MovementCommands` - go, move, movehere, goto, playerhelproom, playertaxi
  - `CombatCommands` - fight, kill, killget, killge, hit, touxi, perform, zhandou, halt, beg, steal
  - `InventoryCommands` - i, get, drop, give, exchange, wield, unwield, wear, unwear, fill
  - `CommunicationCommands` - say, chat, rumor, newbie, party, tell, wizchat, chatphiz, rumorphiz, newbiephiz, sayphiz, turnoff, turninfo, black, unblack, vote
  - `SkillCommands` - skills, bskills, enable, lian, xue, bai, fangqi, readBook, tuna, dazuo
  - `StatusCommands` - hp, score, look, look_b, hp_b, skills_b, score_b, i_b, who, timeuse
  - `EconomyCommands` - buy, eat, drink, check, withdraw, deposite
  - `QuestCommands` - quest, giveup, ge, letsWork, letsCaikuang, letsDazao, letsSendThing, letsKillAll, getReward, cunquit, cdelQuest
  - `FactionCommands` - fnCreateFaction, fnCmdFaction, fnDisband, fnJoinFaction, fnAgreeJoin, fnFireOut, fnUnJoin, fnExalt, fnMyFaction, fnDemise, fnSetFactionColor, fnSetFactionBanner, fnSalute, fnInvite, fnFactionParty
  - `LifeCommands` - sleep, sit, knock, open, follow, nick, describe, uselevel, ageup, dorenew, wimpy, quit, cquit
  - `WizardCommands` - wizset, wizsets, wizkickout, wizsetadd, wizsetsb, wizsetssb, wizsetaddsb, wizget, wizgoto, wizkick, wizclose, wizopen, wizlook, wizcreate, cmd_reload, shutdown, errorChat

**3.4 战斗系统** - 对应 yactor.cpp 战斗逻辑 + fightmiaoshu.cpp
- `CombatService` - 战斗流程(攻击/防御/闪避/招架/伤害计算)
- `CombatMessageService` - 战斗描述生成(刺伤/砍伤/空手伤/咬伤/毒伤/伤害描述/停手描述)
- 武功级别描述(36级从"不堪一击"到"至尊无敌")

**3.5 房间系统** - 对应 yroom.cpp + 各特殊房间类
- `RoomService` - 房间加载、进入/离开、显示人员/物品
- 特殊房间类型(对应原项目各类):
  - `BankRoom` (ybankroom) - 存取款
  - `PawnRoom` (ypawnroom) - 当铺
  - `CookRoom` (ycookroom) - 厨房
  - `RetiringRoom` (yretiringroom) - 休息

  - `YelianRoom` (yyelianroom) - 冶炼
  - `LiandanRoom` (yliandanroom) - 炼丹
  - `NewPlayerRoom` (ynewplayerroom) - 新玩家

**3.6 特殊NPC** - 对应 ynpc子类

### Phase 4: WebSocket实时通信

**4.1 WebSocket配置**
- `WebSocketConfig` - STOMP endpoint `/ws`, 应用前缀 `/app`, 话题前缀 `/topic`
- `WebSocketAuthInterceptor` - 连接时JWT认证

**4.2 消息通道设计**
- `/app/command` - 玩家发送命令
- `/topic/room/{roomId}` - 房间广播(人员移动/说话/战斗)
- `/queue/player/{playerId}` - 玩家私有消息(战斗结果/系统提示)
- `/topic/chat/{channel}` - 聊天频道(公共/新手/谣言/门派/帮派/巫师)
- `/topic/system` - 系统公告

**4.3 WebSocket控制器**
- `GameWebSocketController` - 处理命令消息，路由到CommandRouter
- 消息推送服务 `GameMessageService` - 向玩家/房间/频道推送消息

### Phase 5: 定时任务系统

- `PlayerRecoveryTask` - 气血/精力/内力恢复 (30秒)
- `FoodConsumeTask` - 食物饮水消耗 (60秒)
- `AgeGrowthTask` - 年龄增长 (24小时)
- `RoomRefreshTask` - 房间刷新NPC/物品 (15分钟)
- `OfflineDetectTask` - 掉线检测 (15分钟无操作)
- `QuestTimeoutTask` - 任务超时检查
- `CombatRoundTask` - 战斗回合 (5秒)

### Phase 7: 游戏主界面 (核心)

**7.1 布局** - 对应 login1.cpp 中 printMUDHTML 的布局
- `GameView.vue` - 主容器，分为四大区域:
  - 左上: 房间描述区 (ifrmroom -> RoomDescription.vue)
  - 左中: 游戏画面区 (人物Sprite移动、战斗动画 -> GameCanvas.vue)
  - 左下: 命令输入区 (频道选择 + 文本框 + 发送 -> CommandInput.vue)
  - 左底: 快捷按钮栏 (20个可配置按钮 -> QuickButtons.vue)
  - 右上: 状态面板 (体力/技能/状态/物品切换 -> StatusPanel.vue)
  - 右中: 信息窗口 (战斗/系统消息 -> MessageWindow.vue)
  - 可切换: 地图窗口 / 按钮设置 / 信息窗口

**7.2 游戏画布组件** - 替代原Java Applet
- `GameCanvas.vue` - 房间2D画面，人物移动、战斗动画
- `ActorSprite.vue` - 人物精灵(男女各5种姿态GIF -> 改用CSS动画或Canvas)
- 人物移动动画、说话气泡、战斗动画、死亡动画

**7.3 状态面板**
- `HpPanel.vue` - 气血/精力/内力/食物/饮水条 (对应 hp.html)
- `SkillsPanel.vue` - 武功列表 (对应 skills_b)
- `ScorePanel.vue` - 人物状态 (对应 score_b)
- `InventoryPanel.vue` - 物品列表 (对应 i_b)

**7.4 信息窗口**
- `MessageWindow.vue` - 滚动消息显示，支持自动滚动/暂停

**7.5 命令输入**
- `CommandInput.vue` - 频道下拉(命令/说话/公用/谣言/新手/门派) + 文本输入 + 历史记录
- 支持 `/` 命令、`'` 说话快捷、快捷按钮

### Phase 8: WebSocket通信层

**8.1 WebSocket服务**
- `websocket.ts` - STOMP客户端连接管理
- 自动重连机制
- 消息订阅: 房间消息、私人消息、聊天频道、系统消息

**8.2 Pinia Store**
- `useGameStore` - 游戏全局状态(当前房间、房间内人物列表、画面坐标)

- `useChatStore` - 聊天消息(各频道消息列表)
- `useCombatStore` - 战斗状态(对手、战斗描述)
- `useConnectionStore` - 连接状态、在线人数

### Phase 9: 辅助页面

- `LoginView.vue` - 登录页(对应 index.php)
- `RegisterView.vue` - 注册页(对应 register)

## 关键设计决策

- **游戏状态管理**: 玩家在线时游戏对象驻留Redis，定期同步到MySQL；离线时从MySQL加载
- **房间管理**: 房间数据从MySQL加载，活跃房间缓存在Redis，长时间无玩家的房间释放
- **命令处理**: WebSocket接收命令 -> CommandRouter分发 -> 对应CommandHandler执行 -> 通过WebSocket推送结果
- **战斗系统**: 服务端维护战斗状态，每5秒一个回合，结果实时推送到前端
- **聊天系统**: 消息通过Redis Pub/Sub分发到各频道，持久化到MySQL
